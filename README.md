# 病主緩和臨床指引模板（網頁填寫版）

單一檔案 `index.html`，不需後台、不需安裝。以學會版模板 v0.41 之共通基準為內容來源，依現行法。

外觀採為愛前行基金會橘紅色系（珊瑚紅 #EA5E6A→橘 #F38C5B 漸層），標題宋體、內文黑體；手冊預覽與列印維持標楷體。

## 功能

- **選學會**：16 個已邀請之醫學會（名單依啟航工作坊企劃之「目前已邀請之醫學會」），另有「【測試用】工作坊練習」（可建立多組邀請碼、核心團隊可刪除）。
- **角色自動帶出**：階段三可擔任確診之款別與第五款疾病，以及階段三之角色（主責／轉介／待確認），由檔案內 `SOCIETIES` 資料表依細則§10–13與第五款公告預設；階段一、二、四、五之角色尚無定義，待核心小組討論後填入，目前一律顯示「待確認」。學會均不勾選。
- **逐階段填寫**：各階段如章節排列；共通基準以「共通基準　依現行法」收合框呈現，本會填寫以卡片呈現（珊瑚紅標題列），共八格（1-A、2-A、2-B、3-A、4-A、4-B、4-C、5-A），每格只列題目，內容與篇幅由學會自訂；每格第一句自動彙整為「本會建議一覽」。【3-A】附本會可擔任確診之款別清單；預設為轉介之學會，題目自動改為轉介或會同之專科與流程。
- **手冊預覽**：自動組成「○○醫學會病主緩和臨床指引」，章節順序同 v0.41：封面、本指引之定位、一總覽、二五階段一覽、三本會角色、四本會建議一覽（自動彙整各格第一句）、五各階段、六病歷記載檢核、七參考文獻、附錄一法條速查、附錄二標籤說明與縮寫對照表。
- **列印／存成 PDF**：A4、標楷體、頁碼。未填寫之神經醫學會目前 14 頁；舊樣張（`樣張_台灣神經醫學會_未填寫.pdf`）。
- **草稿**：自動存於本機瀏覽器；「匯出草稿檔」產生 JSON 交核心團隊，「匯入草稿檔」可在另一台電腦續填或由核心團隊檢閱（首頁「本機試填」卡片亦可直接匯入）。本機匯入若將覆蓋既有內容，會先確認；雲端匯入一律先確認，並先將各格原內容存為歷史版本。

## 雲端協作（Firebase）

- 起始頁三個入口：**以邀請碼進入**（雲端協作）、**本機試填**（不連線）、**核心團隊**（Google 帳號登入）。
- 各學會一份雲端草稿，文件 ID 即邀請碼；邀請連結格式 `https://dyfang1.github.io/pspg-template/#k=邀請碼`。
- 同一學會之成員即時共同編輯；每格顯示最後修改者與時間；每格約每五分鐘自動保留歷史版本，可還原。
- 核心團隊登入後可看各學會進度、建立邀請碼、檢閱與修改，並於每格填寫「核心團隊意見」（研發小組看得到、不能改）。
- 安全規則見 `firestore.rules`；核心團隊名單在 Firestore 之 `config/admins` 文件、`emails` 陣列，於 Firebase 後台維護。
- Firebase 設定（apiKey 等）寫在 `index.html` 之 `FIREBASE_CONFIG`；此設定依 Firebase 設計可公開，資料保護靠安全規則。

## 部署（GitHub Pages）

1. 在 GitHub 建一個 repository，上傳 `index.html`。
2. Settings → Pages → Source 選 `main` 分支根目錄，存檔。
3. 約一分鐘後網址為 `https://<帳號>.github.io/<repository>/`。
4. 可直接帶學會開啟：網址後加 `#cardio`、`#neuro` 等（代碼見 `SOCIETIES` 之 `id`）；加 `-book`（如 `#neuro-book`）直接開手冊預覽。

## 維護

- **改共通基準**：改 `STAGES`、`SIT_TABLE`、`COMMON`、`OVERVIEW`、`RECORDS`、`LAWS`、`ABBR` 等常數。與 docx 建置腳本 `_工具/build_學會版docx.py` 同源，兩邊須同步。
- **改學會角色或確診資格**：改 `SOCIETIES`。欄位：`m1`（第一款）、`n23`（第二、三款）、`n4`（第四款）取值 `yes`／`member`／`gray`／`no`；`k5` 以第五款公告之專科關鍵字對應狀態；`r3` 為階段三角色 `lead`／`co`／`ref`／`tbd`；其餘階段之角色於 `profile()` 一律設為 `tbd`，定案後再擴充欄位。
- **新增學會**：於 `SOCIETIES` 增列一筆即可。

## 已知限制（原型）

- 草稿格式為第 2 版，與第一版原型（含心臟示例）之草稿檔不相容；第一版放在 `舊版/`，不要上傳。
- `SOCIETIES` 全部為核心團隊預設草案，標「待確認」者待核心小組會議討論。
- 「台灣神經醫學會」名稱依邀請名單照錄，與資料夾名「台灣神經學學會」不一致，待核。
